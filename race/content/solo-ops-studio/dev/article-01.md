# A One-Page Packing and Shipping SOP for a Small Shop

Most small shops do not have a shipping problem. They have a memory problem. The steps live in one person's head, and they drift a little every week: the thank-you card gets skipped, the label printer runs out mid-batch, an order goes out with the wrong variant. A one-page SOP fixes that by writing the steps down once and running them the same way every time.

This article walks through how to build that page. The goal is a single sheet you can print, tape above your packing table and hand to a helper without a ten-minute explanation.

## Why one page

A long manual does not get read at the packing table. One page forces you to keep only the steps that matter and to write them as actions, not advice. If a step does not fit, it probably belongs in a separate SOP (returns, damaged items, international customs) that you link to by name.

## Step 1: Map the station before you write the steps

Stand at your packing area and list what you reach for, in order. A typical layout has four zones:

1. **Inbound:** printed order list or packing slips, sorted by ship-by date.
2. **Pick:** shelves or bins, each labelled with the same SKU or short code you use in your listings.
3. **Pack:** boxes and mailers by size, filler, tape, inserts, a small scale.
4. **Outbound:** labels, a tray for sealed parcels, and the carrier drop-off bag.

Write the zones across the top of your page as a simple grid. The rest of the SOP follows that left-to-right order, so the sheet matches the room.

## Step 2: Write the core steps as a numbered list

Keep each line short and start it with a verb. Here is a starting version you can copy and edit:

1. Print today's orders, sorted by ship-by date, oldest first.
2. For each order, pick the item and check the variant (size, colour, personalisation) against the slip.
3. Inspect the item for marks, loose parts or print errors. If it fails, set it aside and log it (see the exception log).
4. Choose the smallest box or mailer that fits the item with protection on all sides.
5. Wrap fragile items, add filler, and do a shake test. Nothing should move.
6. Add the insert: packing slip, care card, and anything you promised in the listing.
7. Seal the parcel and weigh it.
8. Buy and print the label using the weighed figure, not the estimate.
9. Stick the label flat on the largest face, away from seams.
10. Mark the order as shipped and confirm the tracking number is attached.
11. Place the parcel in the outbound tray.
12. At the end of the batch, count parcels in the tray against shipped orders.

Twelve steps fits comfortably on one page and covers the full path from slip to tray.

## Step 3: Add a pre-batch checklist

Most packing delays come from running out of something halfway through. Put a five-line check at the top of the page that you run before the first order:

- Label paper or roll loaded, with a spare within reach.
- Tape gun full.
- At least five of each box size you used last week.
- Inserts printed.
- Scale reads zero with nothing on it.

## Step 4: Add a short exception log

The bottom third of the page is a small table with four columns: date, order reference, what went wrong, what you did. Examples of entries: wrong variant picked, item damaged at inspection, address looked incomplete, out of stock after the order came in.

The log is not paperwork for its own sake. Once a month, read it. If the same exception shows up more than once, change a step. If wrong variants keep appearing, add a line to step 2 asking you to read the variant aloud. If addresses keep looking incomplete, add a step to message the buyer before buying the label.

## Step 5: Add a line for digital orders, if you sell them

If your shop also sells downloads, add one row to the grid: "Digital: open the delivered file on a phone once per new listing." It is not part of the packing flow, but it belongs in the same daily routine, and it catches broken files before buyers do.

## Step 6: Test the page with someone else

Hand the page to a friend or family member and ask them to pack one test order without asking you anything. Every question they ask is a missing or unclear step. Fix the wording, then print a fresh copy.

## Keeping it current

Date the bottom of the page and keep the old versions in a folder. When you change suppliers, box sizes or carriers, update the sheet the same day. A packing SOP that matches last year's materials is worse than none, because people stop trusting it.
