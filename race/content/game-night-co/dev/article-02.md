# The Draft-Night Setup Checklist for Fantasy Commissioners

Draft night is the best night of the fantasy season. It is also the night most likely to stall because the draft order was never confirmed, one manager cannot log in, or nobody knows whether the clock is 60 or 90 seconds.

Treat it like setting up a big board game: lay out the pieces before the players sit down. Below is a checklist split into three time windows. Copy it, adjust it, and run it top to bottom.

## One week before

**Lock the date and time in writing.** Post it once, with a time zone if anyone is remote, and ask for a confirmation from every manager.

**Confirm the draft format.** Snake, auction, or something else. Write down the pick timer, the number of rounds, and whether the platform's auto-draft takes over if someone is absent.

**Set the draft order and publish it.** Whatever method you use (random generator, last season's standings, a live drawing), decide it now and post the result. A draft order announced at the start of the draft invites "that's not fair" from the person picking last.

**Decide the absentee rule.** Choose one and post it:

- The platform auto-drafts for absent managers using its default rankings.
- An absent manager may submit a pre-ranked list.
- A named stand-in drafts for them.

**Check roster settings.** Number of starters per position, bench size, and any flex spots. Changing these after the draft is painful, so confirm them now.

**Share the one-page rules.** Draft night is when people are paying the most attention. Make sure the rules are already pinned.

## Day of the draft

**Send a reminder three to four hours ahead.** Include the start time, the link, and the pick timer.

**Ask everyone to log in early.** Fifteen minutes is enough to sort out forgotten passwords and app updates without delaying the first pick.

**For in-person drafts, set up the room.** Seats with a view of the screen, a power strip, a printed draft order, and a visible timer. A big board on a wall or a whiteboard is a fun touch and helps people who are not staring at a phone.

**Assign a backup commissioner.** If your connection drops, someone else needs to be able to pause the draft. Tell them before the draft, not during.

## First ten minutes

**Do a two-minute rules recap.** Read out only the things that matter tonight: pick timer, what happens if the timer runs out, how keepers (if any) are handled, and when waivers open after the draft.

**Confirm the order on screen.** Ask everyone to check their slot before pick one.

**Start on time.** Starting late punishes the people who showed up early. If someone is missing, the absentee rule you posted last week applies.

## Common draft-night problems and the rule that prevents each

| Problem | Rule to write down in advance |
|---|---|
| Manager drafts an ineligible player | The pick stands if the platform allowed it; otherwise the next eligible player in their queue is used. |
| Pick timer expires | Platform auto-picks; no do-overs. |
| Connection drops for the commissioner | Backup commissioner pauses the draft for up to ten minutes. |
| Wrong player clicked | One undo per manager per draft, only before the next pick is made. |
| Dispute about draft order | The order published one week before is final. |

You do not have to use these exact rulings. The point is that each one is decided before the draft, when nobody's team is at stake.

## After the last pick

**Post the full draft results.** A screenshot or export in the league chat gives everyone a shared record.

**Announce when waivers open.** Many disputes in week one come from people not knowing when free agents unlock.

**Ask for one piece of feedback.** "What should we change for next year's draft?" Write the answers down somewhere you will see them next season.

## Copyable checklist

```
[ ] Date/time confirmed by all managers
[ ] Format, timer, rounds written down
[ ] Draft order decided and posted
[ ] Absentee rule posted
[ ] Roster settings checked
[ ] Rules pinned
[ ] Reminder sent day-of
[ ] Backup commissioner named
[ ] Two-minute rules recap done
[ ] Results posted, waiver opening announced
```
