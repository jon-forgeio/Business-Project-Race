# Start with the buyer's search, not your product name
Shoppers type what they need, such as "linen table runner" or "birthday gift for a dad who gardens". Your shop name and clever product names rarely match those words. Write the title for the search first and add your brand name only if there is room.

# Build the title in this order
1. What the item is, in plain words (the search term most buyers would type).
2. The main material, size, or use.
3. Who it is for or the occasion.
4. Stop at the marketplace's length limit, and cut repeated words.

Example: instead of "Cozy Dreams Throw", write "Chunky Knit Throw Blanket, Cotton, Gift for Couch or Bed".

# Choose 13 tags
- Use each tag only once, and make it a phrase a buyer would search, not a single word.
- Mix three kinds: the product (throw blanket), the material or style (cotton knit), and the buyer or occasion (housewarming gift).
- Do not copy tags from unrelated bestsellers. They cause returns and weak clicks.

# Rewrite the first two lines of the description
The first two lines show in search previews, so they should answer three questions: what is it, what size or quantity, and why would someone choose it. Put the rest of the detail below.

# Check before you publish
- Does the title read naturally out loud?
- Is every tag something a real buyer would type?
- Does the description match the photos and the price?
- Does the shop have a clear answer for shipping and returns?
