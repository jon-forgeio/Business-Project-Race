# How to use these
Replace the [brackets], keep it short, and save each message in your notes app. Guests skim, so lead with the one thing they need.
# 1. Check-in day
"Hi [Name], the home is ready. Door code is [code]. Check-in is from [time]. If anything is unclear, message me here."
# 2. Late arrival
"No problem. The code works any time. I will leave the porch light on. If you hit any trouble, call [number]."
# 3. Something is broken
"I am sorry about that. I will [fix/replace] it by [time]. If it is urgent, call [number]. Thanks for letting me know."
# 4. Noise concern from neighbours
"Neighbours mentioned some noise. Could you keep it down after [time]? Thank you for helping us stay good neighbours."
# 5. Checkout
"Checkout is at [time]. Please start the dishwasher, take out the trash and lock the door. Thank you for being a great guest."
# 6. Review request
"Thanks for staying, [Name]. If you enjoyed the home, a short review would mean a lot. I will review you too."
# Tips
- Decide your rules once (refund thresholds, late checkout, quiet hours) and paste them when needed.
- Send the arrival details two to three days ahead, not on the day.
- Keep a short local-tips message: one coffee shop, one dinner place, one grocery, one family activity.
