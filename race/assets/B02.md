# Read me first
These SOPs assume you sell digital downloads (printables, templates, planners). Each is a checklist. Copy the ones you need into your notes app and edit them to fit your shop. Time estimates assume a solo seller.
# SOP 1: New listing (45 minutes)
- Name the product in a working file name first, then write the customer-facing title.
- Write the first 40 characters of the title to carry the main keyword (what it is and who it is for).
- Add 13 tags: 5 exact phrases a buyer would type, 4 use-cases, 2 occasions, 2 formats.
- Write the description in this order: what you get, file formats and sizes, how to download, what is NOT included, usage terms.
- Upload 10 images: cover, what is included, mockup in use, format list, size chart or preview, FAQ, reviews slot, bundle cross-sell, instruction slide, closing image.
- Set price, turn on automatic delivery, upload the file, then open the listing as a buyer and download it.
# SOP 2: Title, tags and keyword check (15 minutes)
- Type your main phrase in the Etsy search bar and note the suggested endings.
- Use two suggestions in your title and the rest in tags.
- Check the top five results: what do their covers have in common? Do yours differ enough to stand out?
- Log keyword, date and title version in a sheet so you can compare after two weeks.
# SOP 3: Mockup and cover photos (30 minutes)
- Use one consistent background colour across the shop.
- Show the product at its real size beside a recognizable object (pencil, mug).
- Put 5 words or fewer of text on the cover image, readable at thumbnail size.
- Export at the recommended aspect ratio and compress.
# SOP 4: Delivery file QA (10 minutes)
- Open every file on a phone and a laptop.
- Check fonts: embed or include a font list.
- Check page count, margins and orientation.
- Include a 1-page "start here" PDF with licence and support contact.
- Zip large files and test the zip.
# SOP 5: Customer message replies
- Reply within 24 hours. Template: greeting, restate the question, give the answer, link the help page, thank them.
- If a file will not open: ask for the device and software, resend the file, offer a refund if it still fails.
- If the buyer asks for a customisation: state price, turnaround and what is included before agreeing.
# SOP 6: Refund and dispute handling
- Digital files are usually non-refundable, but refund for: defective file, wrong item, duplicate purchase.
- Log each refund with date, reason, product.
- If three refunds in a month come from one product, pause it and fix it.
# SOP 7: Bundle builder (60 minutes)
- Pick 5 to 8 related products that share a theme.
- Price the bundle at roughly 60 to 70 percent of the sum.
- Write a title that names the number of items and the use-case.
- Add the bundle link to the descriptions of each single item.
# SOP 8: Seasonal refresh (90 minutes)
- Eight weeks before a season, list five evergreen products that can take a seasonal cover.
- Update the first image, one tag and the title prefix.
- Schedule the change and set a calendar reminder to revert it.
# SOP 9: Weekly admin (30 minutes)
- Check messages, reviews, favourites and traffic.
- Reply to every review in one sentence.
- Note the top three listings by views and the bottom three by conversion.
- Pick one listing to improve this week.
# SOP 10: Monthly review (45 minutes)
- Record revenue, fees, refunds and net.
- Compare against last month and the same month last year.
- Choose one product to retire, one to refresh and one to create.
# SOP 11: Shop policies template
- Digital products: no physical item shipped, immediate download, no returns on digital files except as listed, personal use unless a commercial licence is purchased, support contact and typical response time.
# SOP 12: New-product launch
- Week -2: pick the idea from search suggestions and your own buyers.
- Week -1: create the file, QA it, take mockups.
- Day 0: publish, share to your shop page, update announcement.
- Day 3: check views and adjust the title or first image.
- Day 14: decide whether to keep, tweak or retire.
